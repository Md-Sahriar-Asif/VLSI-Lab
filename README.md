## 🧪 Lab Projects and Activities

### 1. Full Adder — 1 Bit

Introduces the design of a one-bit full adder, a fundamental combinational logic circuit used to perform binary addition.

**Key focus:**
- Binary addition
- Sum and carry-out generation
- Combinational logic design

### 2. Full Adder — 8 Bit

Extends the full-adder concept to an eight-bit circuit for performing multi-bit binary addition.

**Key focus:**
- Multi-bit binary addition
- Connecting adder stages
- Carry propagation

### 3. Register — 8 Bit

Covers the implementation of an eight-bit register for storing and updating binary data.

**Key focus:**
- Sequential logic
- Clock-controlled data storage
- Eight-bit data handling

### 4. ALU — 8 Bit

Focuses on an eight-bit Arithmetic Logic Unit (ALU), a core component of a processor that performs arithmetic and logical operations.

**Key focus:**
- Arithmetic operations
- Bitwise logical operations
- Operation selection and result generation

### 5. Mini 8-Bit Accumulator CPU

Combines fundamental digital system components into a small accumulator-based CPU design.

**Key focus:**
- Program Counter (PC)
- Instruction ROM
- Control Unit
- Arithmetic Logic Unit (ALU)
- Accumulator register
- Zero Flag
- Instruction execution and simulation

### 6. Lab Midterm Materials

Contains the work completed for the lab midterm, along with question papers from other sections for study and reference.

**Purpose:**
- Preserve midterm-related lab work
- Organize question papers
- Support revision and exam preparation

## 🛠️ Tools and Technologies

The tools and technologies used for individual tasks are documented in their respective project folders. The CPU project was developed and simulated using **VHDL and Xilinx ISE**.

## 📈 Version Control and Progress Tracking

Git and GitHub are used to maintain a chronological record of my lab work. Tasks are committed and pushed as they are completed, making it easier to track progress, preserve earlier versions, and maintain an organized history of the semester's activities.

## 🎯 Learning Objectives

Through these lab activities, I aim to:

- Understand the fundamentals of combinational and sequential digital circuits.
- Design and integrate basic hardware components.
- Develop an understanding of arithmetic and logical operations in digital systems.
- Explore the internal organization and operation of a simple CPU.
- Practice hardware description, simulation, debugging, and version control.
- Maintain proper documentation of laboratory tasks and project development.
